# Google GenAI SDK Chat Memory

This example demonstrates how to build a simple conversational AI agent using the Google Generative AI SDK (Gemini API) that maintains context across multiple turns. It showcases the 'long-lived' aspect by leveraging the chat session's built-in memory to provide coherent and context-aware responses, mimicking an agent that learns and adapts within a conversation.

## Language

`python`

## How to Run

1. Set your Google API key as an environment variable: `export GOOGLE_API_KEY='YOUR_API_KEY'`
2. Install the SDK: `pip install google-generativeai`
3. Run the script: `python main.py`
